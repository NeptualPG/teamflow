# HOW TO CREATE A GOOD COMMIT

* git commit -m "<type>: <short summary>" -m "<optional longer explanation>"

### tipical <type> to commits: 

* feat     # New feature
* fix      # Bug fix
* refactor # Code improvement without changing behavior
* docs     # Documentation
* test     # Tests
* chore    # Maintenance/configuration
* style    # Formatting only
